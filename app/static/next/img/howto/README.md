# Show Me How Pictures

Screens of the Firewalla MSP website and the Firewalla phone app, used by the
dashboard's Show Me How steps. Every personal detail in them has been
replaced with a neutral stand-in: device, group, network, Wi-Fi and list
names ("PC 1", "Speakers", "LAN 2", "List 1"...), IP addresses
(192.168.1.x), MAC addresses (AA:BB:CC:00:00:0N) and the account name
("you"). Firewalla's own menus and labels are as they appear.

Firewalla's screens change from time to time, so what you see in the app
or MSP may differ slightly from these pictures.
