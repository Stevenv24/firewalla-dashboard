Set Up

Firewalla Dashboard

    Type the Setup Code

    The setup code keeps anyone else on your network from changing your keys. A new one is made each time the dashboard starts.

    1. On your NAS, open Container Manager › Container, click the dashboard's container (its name ends in dashboard or is the one you chose), then Log.
    2. Find the line SETUP CODE for this start: XXXX-XXXX-XXXX. (It is also in the file config/setup_code.txt in the dashboard's folder, in File Station.)
    3. Type it below and click Continue.
    Picture to come: Container Manager › Container › Log, with the setup code line

    2. Router Access

    The dashboard reads your router through a locked-down connection. You type the router's SSH password once: the dashboard uses it a single time to set up its own key, then forgets it.

    Turn SSH On and Copy the Password

    1. Open the Firewalla app on your phone and tap your box.
    2. Tap Settings › Advanced › Configurations › SSH Console.
    3. Turn SSH on for the network this NAS is on. (On Gold and Purple, each network has its own switch.)
    4. Copy the password shown there. It changes whenever the router restarts; that is fine, the dashboard needs it only this once.
    5. Paste it below and click Connect.
    Picture to come: Firewalla app › Settings › Advanced › Configurations
    Picture to come: the SSH Console screen, with the switch per network and the password
    More (only for two NAS units working as a pair)
    The dashboard's key is accepted only from this NAS's address. With Synology High Availability, add the other unit's own address here.
    Setting up the router and checking it: this takes up to two minutes.

    What happens: the dashboard makes its own key, adds it on the router so it can only open a tunnel to a read-only filter (no commands, no other connections, only from this NAS), puts the read-only filter in place (or uses the one already there), and then tests all of it. Your other keys on the router are left alone. Keep SSH turned on in the app afterwards: if you turn it off, the dashboard stops until you turn it back on.

    4. Firewalla MSP (Optional)

    Only if you use Firewalla MSP. Without it the dashboard still works; the rule pop-ups can't show your target lists.

    1. Open your MSP site in a browser and sign in.
    2. Copy the address from the address bar, up to .firewalla.net, and paste it below.
    3. In MSP, open Settings › API Tokens and click Create.
    4. Name it "Dashboard" and give it read-only access.
    5. Copy the token, paste it below and click Check and Save.
    Picture to come: MSP › Settings › API Tokens › Create, with read-only chosen

    5. Email Alerts (Optional)

    For the daily digest and alerts by email, through your Gmail account. You need a Gmail "app password", not your normal password.

    1. Your Google account needs 2-Step Verification turned on (Google Account › Security).
    2. Go to myaccount.google.com/apppasswords and sign in.
    3. Type "Firewalla Dashboard" as the name and click Create.
    4. Copy the 16-letter password Google shows (the spaces don't matter).
    5. Fill in the boxes below and click Send Test Email.
    Picture to come: Google › App passwords, with the 16-letter password

    6. Ask Claude (Optional)

    Claude can explain findings in plain words. It only reads the facts the dashboard gives it and writes text; it can't change anything. The dashboard works fully without it.

    Use an API key from the Claude Console. Don't use a Claude Pro or Max sign-in: Anthropic's terms don't allow that for an app like this.
    1. Go to console.anthropic.com and make an account (or sign in).
    2. Open Billing, add a card and buy some credit, for example $10.
    3. Open Limits and set a monthly spend limit, for example $20. That is your safety cap.
    4. Open API Keys, click Create Key, name it "Dashboard" and copy it (it is shown only once).
    5. Paste it below and click Save.
    Picture to come: Claude Console › Limits, with a monthly spend limit
    Picture to come: Claude Console › API Keys › Create Key

    Rough cost: about $5 to $20 a month for a home network; the dashboard's daily limits keep it under about $60 even when used a lot.
